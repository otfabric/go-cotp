# Testing

All tests are in the root package and need no network beyond loopback, no Docker and no hardware. There are no prerequisite-gated tests, so there is no `*_REQUIRE_*` variable.

## Tiers

| Tier | Command | What it runs |
|---|---|---|
| Unit and service | `make test` | Codec, negotiation, handshake, TSDU and open-state tests |
| Short | `make test-short` | The same with `-short` (no test currently shortens itself) |
| Race | `make test-race` | The same with the race detector |
| Coverage | `make coverage-check` | Fails below 90% |
| Fuzz | `make fuzz` | Every `Fuzz*` target for `FUZZTIME` (default 5s) |
| Selected fuzz | `make fuzz-decode`, `make fuzz-parse` | `FuzzDecode`; the two parameter parsers |
| Benchmarks | `make bench` | `bench_test.go` |
| Cross-compile | `make cross` | Build only, without cgo; no test runs on these platforms |
| Everything local | `make check` | Formats and tidies, then vet, staticcheck, golangci-lint, govulncheck, tests, race, coverage report |

`make lint`, `make lint-ci` and `make vuln` need `staticcheck`, `golangci-lint` and `govulncheck` on `PATH`. `make check` runs `make coverage`, which prints coverage but does not enforce the minimum; run `make coverage-check` as well.

CI (`.github/workflows/ci.yml`) runs the shared go-ci workflow on Go 1.23 to 1.26 with the race detector, coverage minimum 90, govulncheck and 10 seconds per fuzz target, and a `closure-gates` job: module verify, staticcheck and the fuzz seed corpus.

## Where things are tested

| Files | Scope |
|---|---|
| `decode_*_test.go`, `wire_test.go`, `params_test.go`, `golden_test.go` | Codec, golden hex in `testdata/unit/` and `testdata/captures/` |
| `size_*_test.go`, `handshake_validation_test.go`, `reference_allocator_test.go` | Negotiation and references |
| `connect_test.go`, `accept_test.go`, `open_state_test.go`, `tsdu_test.go` | Service state machine |
| `integration_test.go` | Client and server of this package, in memory |
| `tcp_test.go` | The same on localhost TCP |
| `adversarial_test.go` | A raw peer sending bad sequences |
| `tp0_fixture_test.go` | Fixtures in `testdata/tp0/`, generated by this package ([README](testdata/tp0/README.md)) |
| `tpkt_integration_test.go` | Composition with go-tpkt |
| `leak_race_test.go`, `duplex_test.go`, `deadline_test.go` | Unblocking on close, concurrency, per-direction deadlines |
| `engine_fuzz_test.go` | Fuzz at the engine boundary |

All peers here are this package or a test-written raw peer: nothing in this repository runs against an independent COTP implementation ([LIMITATIONS.md](LIMITATIONS.md#not-verified)).

## Coverage policy

The minimum is 90% of statements of the root package. It is set in `Makefile` (`COVERAGE_MIN`) and `.github/workflows/ci.yml` (`coverage-min`). Nothing is excluded: the module has one package.

## Fuzz regressions

`go test -fuzz` writes a failing input to `testdata/fuzz/<Target>/`. Fix the bug, commit that file, and it runs as a seed in every `go test` from then on. Do not delete a corpus file to make a test pass.
